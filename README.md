# ProСТО — сайт автосервиса в Тольятти

Одностраничный сайт круглосуточного автосервиса и автотехцентра ProСТО.
HTML + CSS + JavaScript, без сборщика. Шрифты и Motion лежат локально.

## Источники контента

- марки автомобилей и виды запчастей;

В карточке нет опубликованного прайс-листа, поэтому цены на сайте не выдумывались:
стоимость предлагается уточнять при записи.

## Структура

- `index.html` — разметка, метатеги, JSON-LD AutoRepair;
- `css/style.css` — дизайн-система, адаптив, состояния;
- `js/main.js` — меню, лайтбокс, фокус-ловушки, анимация первого экрана;
- `js/motion.js` — Motion (vanilla, локальная копия);
- `fonts/` — Tektur и Inter с кириллицей (Google Fonts, OFL);
- `img/` — фотографии из альбома, favicon, OG-картинка, статическая карта.

## Типографика

Заголовки — Tektur, основной текст — Inter. Кириллица Tektur проверена рендером
до деплоя; обводок (`-webkit-text-stroke`) нет. Телефоны набраны системным шрифтом.

## Мобильная версия

У фиксированной шапки на мобильных отключён `backdrop-filter`, бургер выровнен
через `margin-left: auto` и лежит выше панели меню, номер телефона продублирован
в панели меню.
